JNE Paket Tertunda

Domain palsu: jne-paket-tertunda.example  ·  10.10.2.66

Ini halaman statis untuk lab Return to Sender (Group 2). Halaman ini sengaja terlihat seperti bait paket tertunda, tapi tidak ada form, tidak ada tombol login, dan tidak mengumpulkan data apa pun.

  • Kalau filter DNS/firewall mati, klien LAN bisa membuka halaman ini.
  • Kalau filter nyala, nama domain jadi NXDOMAIN dan IP 10.10.2.66 di-drop iptables di gateway.
